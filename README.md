# AI-Proof harness

The Claude Code setup from the [AI-Proof SaaS bootcamp](https://aiproofsaas.com). It turns Claude Code into your AI co-founder, built for people who don't code.

What you get:
- **A handbook.** The rules Claude follows on every job: plain words, one step at a time, and "done" means it worked live.
- **Skills.** `/setup-check`, `/ship`, `/unstuck` and `/update`. More arrive during the bootcamp.
- **A secret guard.** A hook that stops secrets from landing in the wrong file.
- **A starter product.** A Cloudflare Worker with a database and a built-in AI model, all on Cloudflare's free plan. No API keys.

## Install

1. Make an empty folder called `ai-proof`. On Windows, keep it out of OneDrive.
2. Open the Claude desktop app, go to the Code tab, and open that folder.
3. Paste this:

```
Install the AI-Proof harness here. Run: curl -fsSL https://raw.githubusercontent.com/aiproofsaas/ai-proof-harness/main/INSTALL.md and follow the steps.
```

You need a Claude Pro plan or higher, and a free Cloudflare account to put your product live.

## Your files are yours

Run `/update` any time. It replaces the harness files and never touches your own work.
